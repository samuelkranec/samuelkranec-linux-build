This file contains the main changes I made during the project.

The project was a learning project, so I am not using normal software version numbers here.

## 2026-08-18

### Changed

- Updated the README to match the current repository.
- Checked all files and folders in the repository.
- Removed old `.gitignore` rules from the previous Tauri project.
- Added basic protection for environment files, private keys and temporary files.
- Updated the application documentation.
- Documented the current state of the project.

### Project status

The project is cancelled.

I had to relocate my setup and because of that I decided to stop working on this project.

Instead of continuing with the Linux OS project, I decided that making a homelab would be more useful for me.

I still learned a lot from this project and I can use that knowledge in the homelab.

Some of the things I learned were:

- Linux administration
- Networking
- Storage
- SSH
- UFW
- AppArmor
- Fail2ban
- Automatic updates
- Troubleshooting

I hope that one day I will make a similar project again and go further with it.

My goal would be to eventually create my own operating system from scratch.
